## Diameter Distribution Lab 2.0.1

- **Settings:**
  - methods appear in a grid;
  - formulas and notes are behind a "Details" disclosure for each family;
  - choices, inputs and errors stay visible;
  - a sticky action bar shows how many methods are selected.
- **Results:**
  - parameters and model comparison are merged into one Results tab: one sortable table of all fits, grouped by
    observation process;
  - secondary criteria are behind an "all criteria" switch;
  - notes are in a single list;
  - the full per-family tables are in a disclosure;
  - there are four tabs instead of five.
- **Recovery from summaries:**
  - a guide table shows which methods can be used with the summaries at hand;
  - the three method groups are on separate tabs;
  - the mean, variance, Dq, n and variance divisor are typed once and shared between the groups.
- **Header:**
  - the tool version is shown in the page header of every tool;
  - the release-notes banner is removed;
  - the introduction is shorter.
- **Citations:** the Cite dialog, the README and `CITATION.cff` carry the Zenodo concept DOI 10.5281/zenodo.24135603.

Settings page height on desktop goes from 4033 px to 2614 px. The summary workflow goes from 2979 px to 1313 px.
