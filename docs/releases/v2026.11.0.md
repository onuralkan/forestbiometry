## Diameter Distribution Lab 2.0.0

First multi-distribution version, rewritten on a new engine (`assets/lab/dist/`).

- **Families:** Weibull, normal, lognormal, gamma, fixed-bound beta, Johnson SB, exponential and log-logistic.
- **Fitting:** maximum likelihood, moments (divisor n by default, n − 1 as an option), percentiles and log-moments.
- **Measurement thresholds:** conditional maximum likelihood.
- **Grouped data:** maximum likelihood from class frequencies, with class tables.
- **Parameter recovery from summaries:**
  - normal, lognormal and gamma;
  - Weibull, M2–M10 of Poudel and Cao (2013);
  - Johnson SB with fixed ξ, after Parresol (2003).
- **Model comparison:** KS, AD, CvM, AIC, BIC, AICc, class errors and EI; Q–Q and P–P plots.
- **Bootstrap:** parametric goodness-of-fit p-values; parametric or non-parametric percentile intervals; seed recorded.
- **Sources:** every result shows its method, units, support policy and references.
- **Exports:** Excel, CSV, JSON and SVG, carrying the version, settings, parameters and seed.

The Weibull-only version 1.0.0 is retired. Its code is kept in `legacy/weibull/` as a regression reference.

Tests: every scientific calculation is checked against an independent reference (`tests/`).

Details: `docs/METHODS.md` §12 and `docs/DIST_P15.md`.
