# Tests

Numerical tests need only Node.js (CI: version 22). Browser tests (`e2e.mjs`) need Playwright with Chromium and the site
served locally with `php -S 127.0.0.1:8092` from the repository root. Reference generators (`tests/ref/make_*.py`) need
Python 3 with the packages named in each script (NumPy, SciPy, mpmath, scikit-learn, openpyxl); their outputs are
committed, so the tests run without Python.

## Diameter Distribution Lab 2.0.0 (`assets/lab/dist/`)
- `node tests/dist/test_p01.mjs` … `test_p15.mjs`: one file per stage of the revision (`docs/DIST_SPEC.md`), each against
  `tests/ref/dist_pNN.json`, generated by `python3 tests/ref/make_dist_pNN.py` (SciPy, mpmath, NumPy). P15 checks that every
  reference the tool cites is found in `docs/`.
- `node tests/dist/test_export.mjs`: Excel/CSV export rows (numbers as numbers, decimal point).
- `node tests/dist/e2e.mjs http://127.0.0.1:8092 [shots-dir]`: browser test of the tool (both workflows, every tab,
  exports, bootstrap worker, phone view, load failure).

## Other tools and the site
- `node legacy/test_math.js`: checks the maths in `legacy/tools.js` (retired code, not published) against SciPy reference values.
- `python3 tests/ref/make_reference.py`: regenerates `tests/ref/distributions.json` (needs numpy + scipy).
- `node tests/checker/test_checker.mjs`: Forest Data Checker acceptance tests (pure logic + vendored SheetJS); expected values written by hand.
- `node tests/stand/test_stand.mjs`: Plot & Stand Metrics tests; references are the acceptance example and `tests/ref/stand.json`.
- `python3 tests/ref/make_stand_reference.py`: regenerates `tests/ref/stand.json` from `tests/stand/fixture.json` (numpy).
- `node tests/stand/e2e.mjs http://127.0.0.1:8092 [shots-dir]`: browser test for Plot & Stand Metrics.
- `node tests/eval/test_eval.mjs`: Model Evaluation tests; references are the acceptance example and `tests/ref/eval.json`.
- `python3 tests/ref/make_eval_reference.py`: regenerates `tests/ref/eval.json` from `tests/eval/fixture.csv` (scikit-learn + numpy).
- `node tests/eval/e2e.mjs http://127.0.0.1:8092 [shots-dir]`: browser test for Model Evaluation.
- `node tests/weibull/test_weibull.mjs`: retired Weibull-only Diameter Distribution Lab 1.0.0 (`legacy/weibull/`), kept as a regression reference, against `tests/ref/weibull.json`.
- `python3 tests/ref/make_weibull_reference.py`: regenerates `tests/weibull/fixture.json` and `tests/ref/weibull.json` (fixed seed; numpy + SciPy).
- `node tests/rank/test_rank.mjs`: Relative Ranking tests against `tests/ref/rank.json`.
- `python3 tests/ref/make_rank_reference.py`: regenerates the synthetic sample workbook and `tests/ref/rank.json` (numpy + openpyxl).
- `node tests/rank/e2e.mjs http://127.0.0.1:8092 [shots-dir]`: browser test for Relative Ranking.
- `node tests/checker/e2e.mjs http://127.0.0.1:8092 [shots-dir]`: browser test with Playwright/Chromium against a local `php -S 127.0.0.1:8092` in the site folder.
- `node tests/site/e2e.mjs http://127.0.0.1:8092 [shots-dir]`: browser test for the site shell (tools index, About, language, removed pages).
- `node tests/hd/test_hd.mjs`: Height–Diameter Modelling tests against `tests/ref/hd.json` (SciPy least_squares, scipy.stats.t, numpy) plus acceptance cases.
- `python3 tests/ref/make_hd_reference.py`: regenerates `tests/hd/fixture.csv`, the sample file `assets/lab/hd/ornek/ornek-boy-cap.csv` and `tests/ref/hd.json` (fixed seed; numpy + SciPy).
- `node tests/hd/e2e.mjs http://127.0.0.1:8092 [shots-dir]`: browser test for Height–Diameter Modelling (incl. measured vs predicted heights in the export).
- `node tests/sampling/test_sampling.mjs`: Inventory Sampling Planner tests against `tests/ref/sampling.json` (scipy.stats.norm, numpy) plus acceptance cases.
- `python3 tests/ref/make_sampling_reference.py`: regenerates the sample pilot file, `tests/sampling/fixture.csv` and `tests/ref/sampling.json`.
- `node tests/sampling/e2e.mjs http://127.0.0.1:8092 [shots-dir]`: browser test for the Inventory Sampling Planner.
- `node tests/site/test_cite.mjs`: citation strings of the Cite dialog and tool versions shown by the site (= `TOOL.version`).
- `node tests/site/test_guide.mjs`: the user guide (`kilavuz.php`, `inc/guide/`): same sections in TR and EN, a section per tool, labels it names present in the tools' interface strings, defaults equal to the code.
- `node tests/site/test_format.mjs`: shared number display and decimal-separator defaults (independent of the interface language).
