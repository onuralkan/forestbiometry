# Örnek dosyalar / Sample files

Bu iki dosya **uydurma, gerçek olmayan** deneme verisidir; yalnızca Veri Denetçisi'nin
kontrollerini göstermek için hazırlanmıştır. Hiçbir ölçüme, meşcereye veya yayına dayanmaz.

These two files are **synthetic, not real** data, made only to demonstrate the checker.

- `agaclar.csv`: `;` ayırıcı, ondalık virgül. 001 ile 1 ayrı alanlardır. Bilerek konmuş sorunlar:
  aynı ağacın iki dönemi (sorun değil), mükerrer kayıt (002/3/2019), sayıya çevrilemeyen değer
  (`27,x`), 003'te çelişen alan (800/600 m²), çap 245 cm (sınır dışı), boy 2,1 m (incelik),
  `pb ` (büyük/küçük harf ve boşluk), eksik boy.
- `ornek-alanlar.csv`: 004 numaralı alanda ağaç yoktur (boş örnek alan).
